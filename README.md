Edit `privacy-policy.md` or `terms-of-service.md` directly and push to the `main` branch. GitHub Pages will automatically rebuild the site within a minute or two. Remember to update the "Last updated" date at the top of whichever file you change.

## ⚙️ About the Bot

Sorasaki Hina is a Discord bot featuring:
- Music playback (SoundCloud / Lavalink)
- AI chat assistant (powered by Google Gemini)
- Server moderation tools
- Reminders, server/user info, and mini-games

This repository contains only the legal/policy pages — not the bot's source code.
